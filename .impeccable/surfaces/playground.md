# Physics workbench

Mode: Operate.

The first viewport contains the selected scene, two engine selectors, playback
controls, and editable settings. A narrow scene list supports quick switching.
Desktop places settings beside the simulation. Mobile places settings below it.
The two simulations share camera controls and simulation ticks.

Use a light application frame for readable forms and results. A dark simulation
stage keeps body silhouettes and joint connections legible. Teal identifies
Avian; amber identifies Rapier. Text identifies engines independently of color.
Use system sans-serif for controls and tabular numerals for measurements.

The main action runs a measured comparison. It pauses playback and reports
progress. Result rows show the metric, runtime, versions, and sample settings.
Resetting the scene after changing an engine preserves the configured seed.
Controls communicate that reset. Errors offer a retry without hiding settings.

Avoid promotional copy, card grids, nested panels, and decorative animation.
The simulation itself provides motion. Necessary method details live in a
separate readable view, with a short timing label beside measured output.
