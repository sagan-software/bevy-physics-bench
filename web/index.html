How measurements work

The timed operation

Avian, Rapier, and native Jolt run inside a headless Bevy app with a fixed timestep. Browser Jolt uses its JavaScript binding and a separate timing scope. Inverse kinematics measures Bevy animation work. A sample times a batch of simulation steps, including Bevy integration and synchronization. Scene construction, warmup, snapshots, rendering, and time between samples are excluded.

The runner recreates each scene for every repetition and alternates engine order. Median and p95 describe batch averages in milliseconds per step. P95 is the nearest-rank percentile. The standard deviation uses the whole sample population.

What a comparison means

The engines share geometry, seed, timestep, gravity, friction, restitution, and collision policy. Avian substeps and Rapier solver iterations do different work. Enabled sleeping uses each engine's thresholds. These settings affect both cost and physical behavior.

The native runner and WebAssembly runner form separate series. Browser timings depend on browser version, hardware, timer precision, background activity, and thermal state. Keep the tab visible during a measured run. Large dispersion needs another run before drawing conclusions.

Versions and capabilities

These simulations use Bevy 0.19.1, Avian 0.7.0, and bevy_rapier 0.36.0. The Rapier plugin includes Rapier 0.35.0-glamx0.2. The newest Bevy release, 0.20, does not yet have a mutually compatible published set of these integrations.

Avian and Rapier simulate on the CPU. WebGL renders their poses. The WebAssembly baseline uses one thread and SIMD128. Jolt uses Oxijolt 1.0.1 with Jolt 5.6.0 natively and jolt-physics 1.1.0 in the browser. Jolt substeps retain ten velocity passes and two position passes.

Experimental Nexus 0.6.0 supports 3D piles, stacks, static fields, dominoes, chains, and ragdolls. It requires WebGPU, disabled sleeping, and discrete collision detection. GPU totals include completion and pose readback, reported separately in JSON. Its browser binding timings are separate from Bevy integration timings.

Contribute a result

Export a browser run or use the native command in the repository. Submit its JSON file through a pull request. Validation checks the record and its samples. A submission does not upload automatically.
